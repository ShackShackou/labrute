Import depuis JPEXS

Utilisez JPEXS Free Flash Decompiler pour extraire les sprites des fichiers SWF originaux de LaBrute.

Chemin : C:\ProgramData\Microsoft\Windows\Start Menu\Programs\JPEXS Free Flash Decompiler

Instructions d'Import

  1. Ouvrez le fichier SWF dans JPEXS
  2. Naviguez vers Symbol460 (homme) ou Symbol752 (femme)
  3. Exportez en séquence PNG
  4. Importez les fichiers ici
