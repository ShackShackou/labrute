📖 Guide Rapide

🎭 Créer une Brute

  1. Sélectionner le genre : Homme ou Femme
  2. Modifier les parties : Utiliser les curseurs p1-p8
  3. Choisir les couleurs : Peau, cheveux, vêtements
  4. Prévisualiser : Voir le résultat en temps réel
  5. Exporter : Récupérer les configurations

📊 Exemple de Configuration

// Configuration générée par l'outil const bruteConfig = { gender: 'male', body: '01234567890', // 11 parties de corps colors: '00010203040506070809101112131415' // 16 couleurs }; // Utilisation dans LaBrute const brute = new BruteDisplay( bruteConfig.gender, bruteConfig.colors, bruteConfig.body );

🔧 Structure des Données

  • Body String : 11 caractères hex (p1,p1a,p1b,p2,p3,p4,p5,p6,p7,p7b,p8)
  • Color String : 32 caractères décimaux (16 couleurs × 2 chiffres)
  • Genre : 'male' ou 'female' avec limitations spécifiques
