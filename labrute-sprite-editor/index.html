Aide - LaBrute Sprite Editor

🎯 Comment utiliser cet outil

  • Prévisualisation : Voir la brute en temps réel avec vos modifications
  • Body Parts : Modifier les parties du corps (p1-p8) avec les curseurs
  • Couleurs : Changer les couleurs de peau, cheveux, vêtements
  • Export : Copier les configurations pour les utiliser dans LaBrute

🔧 Parties de Corps

  • p1, p1a, p1b : Éléments principaux et compléments
  • p2 : Corps secondaire (7 variants hommes, 0 femmes)
  • p3 : Corps principal (11 variants)
  • p4 : Accessoires corps (5 hommes, 3 femmes)
  • p5 : Élément spécial (1 variant)
  • p6 : Accessoire secondaire (1 homme, 0 femmes)
  • p7, p7b : Parties supérieures (6 + 2 variants)
  • p8 : Parties finales (4 variants)

🎨 Système de Couleurs

  • col0, col0a, col0c : Couleurs de peau
  • col1, col1a, col1b, col1c, col1d : Couleurs de cheveux
  • col2, col2a, col2b, col3, col3b, col4, col4a, col4b : Vêtements et accessoires
