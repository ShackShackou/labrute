Features Implemented

  • ✓ Hover Activation: Tooltip appears on PFP hover
  • ✓ Mouse Tracking: X position follows mouse, Y stays anchored
  • ✓ Anti-flicker: 120ms delay on hide
  • ✓ Global Tooltip: Single DOM element reused
  • ✓ Z-index Priority: Always above canvas (z-index: 10000)
  • ✓ No Click Capture: pointer-events: none

Content Display

  • ✓ Fighter Name: Bold, with ellipsis for long names
  • ✓ Level: Small-caps with weapon icon if equipped
  • ✓ HP: Current HP with heart icon
  • ✓ Stats: STR (red), AGI (blue), SPD (yellow) with bars
  • ✓ Supers: Listed if present, hidden otherwise
  • ✓ Skills: Localized names with word wrap

Positioning

  • ✓ Anchor: Centered above PFP with -4px offset
  • ✓ X-axis: Follows mouse cursor
  • ✓ Clamp: 4px margins from container edges
  • ✓ No Flip: Always stays above portrait

Style

  • ✓ Background: #FFF6D5
  • ✓ Border: 1px solid #8B6534
  • ✓ Border Radius: 6px
  • ✓ Shadow: Soft shadow for depth
  • ✓ Font: system-ui, Verdana, Arial

Debug Parameters

&pixiTooltipTest=1 - Forces tooltip to show on load for testing

&pixiDbg=1 - Enables console logging of position and data
