🔧 Paramètres de test

⚠️ Note importante

Le tooltip ne fonctionne que dans le contexte d'un combat Pixi actif. Utilisez les liens de test ci-dessus pour voir le comportement en situation réelle.

  • ?renderer=pixi - Active le renderer Pixi (requis)
  • &pixiDbg=1 - Active les logs de debug dans la console
  • &pixiTooltipTest=1 - Force l'affichage du tooltip au chargement
